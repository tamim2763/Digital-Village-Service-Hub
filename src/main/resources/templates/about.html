About the foundation

Built as a shared base for multiple teams.

This project is intentionally limited to starter architecture. It gives the platform team a stable Spring Boot foundation while leaving all business workflows for later feature squads.

  • Clean package structure
    Separated by configuration, web, service, data, security, and utility concerns.
  • Future-ready modules
    The user slice is only a sample, so additional modules can be added without refactoring the core.
  • Multilingual UI direction
    The Thymeleaf and Bootstrap foundation supports localized content and responsive layouts.

Starter principles

Follow constructor injection, keep controllers thin, place business rules in services, and move integration details to dedicated packages as the project grows.
